Notes:

- **MPL-2.0** (`cssparser`, `cssparser-macros`, `dtoa-short`, `option-ext`, `selectors`): file-level copyleft. These crates
  are used unmodified; their source is available from the addresses in the table. MPL-2.0 section 3.3 allows them to be
  combined with AGPL code in a larger work.
- **Fonts** (in `app/renderer/fonts/`): Gentium Plus, Literata, Source Serif 4, Inter and Noto Serif Hebrew are under the
  SIL Open Font License 1.1. They are separate data files shipped next to the program, they stay under the OFL, and their
  licence texts and copyright lines are in `app/renderer/fonts/LICENSES.txt`. The OFL does not allow selling the fonts
  by themselves, and it asks that modified versions not use the Reserved Font Names; Timotheos does not modify them.
- **Android**: the app also uses AndroidX Core KTX and the Kotlin standard library (Apache-2.0), the Tauri Android runtime
  (MIT or Apache-2.0) and the phone's own system web view and text-to-speech engine, which are not part of Timotheos. The
  Gradle build's own transitive packages are listed by Gradle at build time and are not reproduced here.
- **Online services**: Timotheos runs no service of its own and needs none. Its "Download modules" window fetches,
  only when the user asks, a list and a module file from the repository the user chose (the Timotheos catalog on GitHub,
  eBible.org, or an address the user added). Those sites and what they offer are not part of Timotheos and stay under
  their publishers' terms. Bible modules the user opens (theWord, e-Sword, USFM) are the user's own files and keep the
  licences of their publishers. One Bible is included, by its translator: see "Bundled Bible" in `NOTICE`.
- **CDLA-Permissive-2.0** (`webpki-roots`): the list of certificate authorities used to check https connections, taken
  from Mozilla. A permissive data licence; it is used unmodified.
