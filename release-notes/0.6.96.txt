Timotheos 0.6.96

- Locate folder button in Options -> Modules: every module row on desktop now has a Locate folder button next to it so you can open the exact folder where that module file or folder is stored.
- Permanent deletion without Rescan restoring deleted files: Delete file now deletes the module file or folder from disk along with any .timotheos-link or .order companion files, records the deletion for archive tracking, and Rescan no longer re-unpacks or restores files you deleted from Timotheos's modules folder.
