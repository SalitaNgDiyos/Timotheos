Timotheos 0.6.132

- A left click on a word looks it up in the Library while a Library panel is open; with none open a click does nothing (right-click → Look up still asks where to put one). 
- Parallel Bibles: the verse column on the left edge is gone; the verse number is a small superscript at the top left of each Bible's text.
- Parallel Bibles opens faster the first time: its Bibles are opened quietly in the background after the app starts, and "Loading…" shows while it reads them.
- Parallel Bibles: when it takes more than 0.3 s to draw, the timing is written to the Developer Tools console (View → Developer Tools) so the slow step can be found.
- Right-click → "Find “word” in this Bible" searches only that Bible in Bible Search (phone: the first open Bible).
- Parallel Bibles, Stacked: a superscript verse number before each Bible's text, the same as Columns; the separate verse heading is gone.
- Bible Search results, Parallel Bibles and the Library use the same text background as a Bible view.
- Download modules: several downloads can run at the same time; each row shows its own progress and a Stop button, and the imports follow one after the other.
- Verse-link popups take the size of their verse (small for a short verse, bigger for a long one), grows wider first, stays inside the app window, and scrolls only when the window is too small. It can still be resized by hand (until it closes).
- The single-commentary view (and the Library entry) use the same text background as the Bible views.
- Where to get modules: the file chooser now opens a moment after the window closes (a possible cause of a crash on some desktops).
- Library: the module list is replaced by group tiles (Commentaries, Dictionaries, Books, Devotionals… and your own groups); click a tile to drop down its modules. "Manage groups…" makes, renames, orders and deletes groups and sets the group of each module. The phone Library shows the same groups.
- Library: Read aloud, Print, Export, Properties, Make the file smaller, Drag to scroll and the topic buttons of your own modules are now in the ⋯ menu.
- Library: the topic list stays on the left in a narrow panel (it no longer jumps to the top).
- Verse-link popups close quickly when the mouse leaves the link (they could stay open until the mouse reached another word).
- Popups on tagged Bible words (Strong's, morphology, footnotes) are back to the old way: a fixed size that you set by dragging the corner, and Timotheos remembers it.
- Floating windows: they move by their caption at any time (no need for Edit Layout), can go partly past the window's edges, and never dock while dragged (use the Dock button). Floating a panel leaves its place empty, so no other panel grows or shrinks; Dock puts it back into that place.
- Pop out: a new button on each panel's caption moves the panel into a window of its own that can go anywhere on the screen (another monitor too). Its place in the main window stays empty. Closing it just closes it; Timotheos remembers the open ones (place and size) and opens them again at the next start. Popped-out windows use the main window's engine, so notes and highlights show in every window; option changes made in a popped-out window stay in that window. Closing the main window closes them all.
